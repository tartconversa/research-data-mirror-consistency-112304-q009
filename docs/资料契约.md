# 资料契约

所有记录均为本地合成数据，使用 UTC 时间或 ISO 日期。标识字段用于关联文件，版次、状态、缺失、撤回和待审核值保留各自原始含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `datasets.csv` | `dataset_id`, `owner_lab`, `sensitivity`, `release_version`, `share_scope`, `release_state` | 42 |
| `source_partitions.csv` | `dataset_id`, `partition_key`, `source_version`, `checksum`, `updated_at`, `withdrawal_state` | 100 |
| `replica_tasks.csv` | `task_id`, `dataset_id`, `region`, `partition_key`, `target_version`, `attempt`, `task_state`, `completed_at` | 120 |
| `replica_objects.csv` | `task_id`, `object_key`, `checksum`, `metadata_version`, `access_policy_version`, `verified_state` | 120 |
| `consumer_requests.csv` | `request_id`, `consumer_lab`, `dataset_id`, `region`, `requested_scope`, `requested_at`, `decision`, `snapshot_ref` | 60 |

缺失值、争议状态、部分成功和待复核均不表示零值或已完成。原始值不预置分析结论，转换依据及研究解释须由应用能力提供。
